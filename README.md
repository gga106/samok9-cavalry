# Samok9
<img width="400" height="225" alt="Samok9Test" src="https://github.com/user-attachments/assets/c4ae0505-2023-4068-a35d-d196085b05a5" />

This script automates wireframe rendering in Cavalry. It is built using 90% AI.

## Features
- **Color Palette by Layer:** Different colors are used for selected layers to distinguish wireframes from one another.

- **Handle and Anchor Markers:** Handles are displayed at corners and midpoints of edges, along with pivot and crosshair markers.

- **Motion Path and Keyframes:** Draw movement paths using direction arrows, frame points, and rotation keyframe markers.


## How to Use
1. Select one or more target layers (shapes, groups, nulls, etc.) in your Cavalry composition.

2. Run `Samok9.js` and click **Build Samok9 Overlay (Selected Layers)**.

3. Click **Render Overlay**, **Clean Render**, **Render Wireframe**, or **Render All 3**. That's it.
